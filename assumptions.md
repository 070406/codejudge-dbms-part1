# Assumptions

1. All IDs are unique identifiers.
2. Student email is unique.
3. Course code is unique.
4. One student can join many courses.
5. One course can contain many students.
6. One submission can generate multiple testcase results.
7. Contest and problems have many-to-many relationship.
8. Raw CSV files may contain duplicate data.
9. Staging tables can be used before normalization.
10. Difficulty values are limited to Easy, Medium, and Hard.
