# CodeJudge Relational Database Design

This repository contains my DBMS Part 1 assignment based on the CodeJudge dataset.

In this assignment, I analyzed the raw CSV files and converted them into a proper relational database schema using DBMS concepts like:

- Entities and Relationships
- Primary and Foreign Keys
- Constraints
- Normalization
- ER Diagram
- SQL Table Creation

## Files Included

- schema.sql
- schema_explanation.md
- keys_and_relationships.md
- normalization_notes.md
- erd.md
- assumptions.md

The schema is designed to reduce redundancy and improve data consistency.
